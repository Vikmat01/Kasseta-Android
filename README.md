# Кассета для Android

Музыкальный плеер для hi-fi плееров на Android 10+. Дизайн как у Кассеты для TrimUI
([Vikmat01/Kasseta](https://github.com/Vikmat01/Kasseta)): чёрный фон, малиновый акцент,
вкладки «Исполнители / Альбомы / Треки», экран плеера с кассетой или CD.

## Установка

Скачайте `Kasseta-vX.Y.Z.apk` со страницы [Releases](https://github.com/Vikmat01/Kasseta-Android/releases/latest)
и установите его (Android попросит разрешить установку из этого источника).

Обновления приходят сами: раз в день при запуске Кассета проверяет последний релиз
на GitHub и, если он новее, предлагает «Скачать и установить». Можно отложить или
пропустить версию.

## Сборка

1. Откройте папку проекта в Android Studio: File → Open → Trust Project.
2. Первая синхронизация сама скачает NDK и CMake 3.22.1 (это ~1 ГБ, нужен интернет).
   Если Studio напишет, что NDK или CMake не найдены: Tools → SDK Manager → SDK Tools →
   отметить «NDK (Side by side)» и «CMake» → Apply.
3. Если Sync пишет «Invalid Gradle JDK» — нажмите «Use Embedded JDK».
4. Подключите плеер по USB (в нём включена отладка по USB) и нажмите ▶ Run.

Первая сборка идёт 5–10 минут: компилируется встроенный FFmpeg для двух архитектур
(arm64-v8a и armeabi-v7a). Следующие сборки быстрые.

### Подпись и выпуск версии

Чтобы обновления ставились поверх, все релизы подписаны одним ключом. Ключ в репозиторий
не кладётся: локально он лежит рядом с проектом как `kasseta-release.jks` +
`keystore.properties`, а на GitHub хранится в секретах `KEYSTORE_BASE64` и `KEYSTORE_PASSWORD`.
Без ключа сборка подписывается отладочным ключом Android Studio.

Новая версия: поднять `versionCode` и `versionName` в `app/build.gradle.kts`, описать
изменения в `release-notes.md`, затем создать тег:

```
git tag v1.2.0
git push origin v1.2.0
```

GitHub Actions соберёт подписанный APK и опубликует релиз, а установленные плееры
предложат обновиться.

## Что умеет

- **Форматы:** FLAC, ALAC, APE, WavPack, TAK, TTA, WAV/W64/RF64, AIFF, DSF, DFF (включая DST),
  WSD, MP3, AAC/M4A, Ogg Vorbis, Opus, WMA (включая Lossless), Musepack, AC-3/E-AC-3, DTS,
  TrueHD/MLP, ATRAC, Shorten, MKA, CAF, AMR. Декодирует встроенный FFmpeg 7.1, системные кодеки не нужны.
- **DSD:** DSD64…DSD512 переводятся в PCM 176,4 кГц (или до выбранного максимума).
  В меню: «DSD: +6 дБ громкости» (DSD записывают на 6 дБ тише PCM) и «DSD: фильтр ультразвука»
  (срез ~45 кГц, убирает шум DSD выше слышимого диапазона).
  Нативного DSD/DoP в Android 10 нет, поэтому вывод всегда PCM.
- **CUE:** отдельные .cue в UTF-8 или Windows-1251; если в CUE написано `Image.wav`, а рядом
  лежит `Image.flac` или `.ape` — найдётся. Встроенный CUESHEET в тегах FLAC/APE/WavPack,
  оглавление FLAC и главы M4B/MKA. Переходы между треками образа без пауз (проверено побитно).
- **Вывод звука:** в родной частоте файла (44,1…192 кГц) без пересэмплирования внутри
  плеера, 32 бит float или 16 бит с дизерингом. Если в настройках вашего плеера есть
  «обход Android SRC» / «Hi-Res» режим (FiiO, HiBy, Shanling) — включите его.
- Воспроизведение без пауз между файлами, ReplayGain (трек/альбом), очередь,
  «играть следующим», перемешивание, повтор.
- Русские теги в старой кодировке (cp1251) читаются правильно.
- Обложки из файлов или из картинки в папке (cover/folder/front.jpg и т.п.).
- Кнопки плеера и наушников, уведомление с управлением, пауза при отключении наушников.
- Вид кассеты зависит от качества: обычная, хромовая, металлическая для hi-res и
  белая керамическая для DSD. Альбомы — обложками, в jewel-кейсах, в кассетных коробках
  или Cover Flow; коробки открываются с анимацией и звуком.
- **Альбом дня:** графитовая коробка с дисками открывается, диски перебираются, и один
  выезжает — альбом на сегодня. Меняется в 0:00, есть «Выбрать другой».
- Поиск по трекам, альбомам и исполнителям, фильтр по качеству.
- Горизонтальный режим (кнопка в шапке плеера) и свой экран блокировки с плеером.

## Управление

- Вкладки — тап или свайп влево/вправо по списку.
- Долгое нажатие на трек/альбом/исполнителя — меню (играть следующим, в очередь…).
- Экран плеера: тап по кассете/CD — сменить вид; свайп влево/вправо — следующий/предыдущий трек;
  перемотка — по полоске прогресса или удержанием «вперёд»/«назад» (со звуком перемотки кассеты).
- ⋮ — меню с настройками звука и обновлением библиотеки.
- Быстрая прокрутка длинных списков — тянуть за правый край экрана.

## Доступ к файлам

На Android 10 плеер попросит разрешение на чтение памяти. На Android 11+ откроется системный
экран «Доступ ко всем файлам» — его нужно включить, иначе CUE и DSD не видны.
Библиотека ищется по всей внутренней памяти и картам памяти; папки Android, LOST.DIR и
скрытые пропускаются.

## Где что в коде

- `app/src/main/cpp/kcore.c` — декодер (FFmpeg → float PCM), точная перемотка, теги, обложки.
- `app/src/main/cpp/kjni.c` — мост в Kotlin. `ffmpeg/` — исходники FFmpeg 7.1 (только нужное
  для звука), `ffmpeg-config/` — готовая конфигурация под Android 10 для каждой архитектуры.
- `Engine.kt` — воспроизведение: AudioTrack, очередь, gapless, CUE-треки, ReplayGain.
- `Scanner.kt`, `Meta.kt`, `Model.kt` — поиск музыки, CUE, исправление кодировок, библиотека.
- `ui/KassetaView.kt` — весь интерфейс; `ui/Cassette.kt`, `ui/Disc.kt` — кассета и CD.
- `ui/DayBox.kt` — «Альбом дня»; `ui/Cases.kt` — jewel-кейс и кассетная коробка.
- `PlaybackService.kt` — фоновое воспроизведение, уведомление, кнопки.
- `LockActivity.kt`, `ui/LockView.kt` — экран блокировки.
- `Updater.kt` — проверка релизов на GitHub, загрузка и установка обновления.

Лицензии: FFmpeg — LGPL 2.1 (`cpp/ffmpeg/COPYING.LGPLv2.1`), шрифты Golos и Caveat — OFL.
